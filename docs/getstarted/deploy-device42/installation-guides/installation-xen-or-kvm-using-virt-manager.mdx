Install the Device42 Main Appliance on Xen- or KVM-based platforms by following the steps in this guide.

## Outline of Installation

1. Download the Device42 image and extract the disk image with `unzip`.
2. Import the disk image and follow the wizard to create a new virtual machine.
3. Log in to the Device42 console and configure the Main Appliance.
4. Set the time zone and configure NTP.
5. Log in to the Device42 Main Appliance from the browser. 

## Illustrated Steps of Installing Device42 using Virt-Manager

Follow these steps to install the Device42 Main Appliance.

### Download the Image and Extract It

The Xen/OpenStack/KVM image downloads as a ZIP file, for example `Device42-19.08.00-qcow2.zip`. The ZIP file contains the disk image in QCOW2 format (`Device42-<version>.qcow2`), a `README.txt` file, and a `Deployment_Guide.pdf` file. When you get the file on the KVM host, run the `unzip` command to extract it:

```bash
unzip Device42-<version>-qcow2.zip
```

### Create the Virtual Machine

1. Select **Import existing disk image** to create a new virtual machine.  

    If you don't see the option to **Import existing disk Image**, follow the [Alternate Install](how-do-i-install-device42-xenkvm-appliance-if-import-existing-disk-image-option-is-missing.mdx) guide.

![Install](/assets/images/wpid6123-Download_and_Install.png)

2. Choose **Linux** as the **OS type** and select Rocky Linux 8 as the **Version**. The Main Appliance runs Rocky Linux 8.

![Choosing OS and version](/assets/images/wpid6121-Choosing_OS_and_version.png)

3. Allocate at least 16 GB RAM and 4 vCPUs for production appliances. See [Sizing Recommendations](../sizing-recommendations.mdx) for larger environments and workloads that use ADM, RU, or storage discovery.

![](/assets/images/wpid6124-media_1326264722468.png)

4. Choose your virtualization type from **Advanced options** and x86_64 for the **Architecture**. Click **Finish**.
   
![](/assets/images/wpid6125-media_1326264734201.png)

### Set Up the Main Appliance from the Console

1. When the import is finished, power on the new virtual appliance.
2. Log in to the console using the default credentials:

    - **Username:** `device42`
    - **Password:** `adm!nd42`

   Change the default password after signing in to the appliance console.

3. Configure a static IP address for the Device42 appliance. From the console menu, choose **(u) Network, Connectivity and Utilities > (n) Network Interfaces**, then select the network interface.

![IP config options v19.05](/assets/images/vm-ip-settings.png)

4. (Optional) Create a DNS entry for the new IP address for the new virtual appliance.

You can apply updates and perform other menu-related tasks using SSH on port `404`, for example, `ssh -p 404 device42@<appliance-IP>`. Port `22` is not used. Root login is disabled.

### Set the Time Zone and Configure NTP

After setting a static IP address, [set the time zone and configure NTP](/administration/setting-time-zone-and-ntp.mdx) to ensure autodiscovery scheduling and log history work correctly.

### Log in to the Web Interface

1. Point your browser to `https://FQDN(Fully Qualified Domain Name) or IP address` to go to the Device42 web UI.
2. Log in to Device42 using the default credentials:
    - **Username:** `admin`
    - **Password:** `adm!nd42` 

    Please change the password as soon as you log in.
