:::info
These are **special case** installation instructions for installing the Device42 appliance on Xen- or KVM-based platforms if the **Import existing disk image** option is missing. Otherwise, please refer to the Device42 [guide to Xen and KVM installation](installation-xen-or-kvm-using-virt-manager.mdx).
:::

## Outline of Alternative Installation

1. Download the Device42 image and extract the disk image with `unzip`.
2. Create a new virtual machine using the **Network Boot** option and complete the installation wizard setup. 
3. Disable **Network (PXE)** from the Device42 virtual machine **Boot Options**.
4. Log in to the Device42 console and web interface as described in the [Set Up the Main Appliance](installation-xen-or-kvm-using-virt-manager.mdx#set-up-the-main-appliance-from-the-console) section and later of the Virt-Manager installation page.

## Illustrated Installation Steps

The following alternative installation steps are similar to the [standard Virt-Manager installation](installation-xen-or-kvm-using-virt-manager.mdx), except that you select the **Network Boot** option instead of importing the Device42 image and then disable the network boot. 

### Download the Image and Extract It

The Xen/OpenStack/KVM image downloads as a ZIP file, for example `Device42-19.08.00-qcow2.zip`. The ZIP file contains the disk image in QCOW2 format (`Device42-<version>.qcow2`), a `README.txt` file, and a `Deployment_Guide.pdf` file. When you get the file on the KVM host, run the `unzip` command to extract it:

```bash
unzip Device42-<version>-qcow2.zip
```

### Create a New Virtual Machine

After you extract the disk image, create a new virtual machine. 

Choose the **Network Boot** option. We'll add the disk later. Make sure you don't have some sort of automated network boot enabled for this machine. You will not see the **Import existing disk image** option.

![Install](/assets/images/wpid2483-Install.png)

### Choose OS and Version

Choose **Linux** as the **OS type** and select Rocky Linux 8 in the **Version** field. The Main Appliance runs Rocky Linux 8.

![Choosing OS and version](/assets/images/wpid2480-Choosing_OS_and_version.png)

Allocate at least 16 GB RAM and 4 vCPUs for production appliances. See [Sizing Recommendations](../sizing-recommendations.mdx) for larger environments and workloads that use ADM, RU, or storage discovery.

![](/assets/images/wpid2484-media_1326264722468.png)

### Choose Disk

![Choose disk](/assets/images/wpid2479-Choose_disk_bunzipped_file_.png)

Choose your virtualization type under the **Advanced options** and select **x86_64** as the **Architecture**.

![](/assets/images/wpid2487-media_1352976855381.png)

### Disable Network Boot

Go to **Details** (1), **Boot Options** (2), uncheck **Network (PXE)**, and click **Apply** (4).

![Disable network boot](/assets/images/wpid2481-Disable_network_boot.png)

### Complete the Setup

Follow the steps outlined in the [Set Up the Main Appliance from the Console](installation-xen-or-kvm-using-virt-manager.mdx#set-up-the-main-appliance-from-the-console) section of the [Xen or KVM Using Virt-Manager - Installation](installation-xen-or-kvm-using-virt-manager.mdx) page to complete the installation of the Main Appliance.
