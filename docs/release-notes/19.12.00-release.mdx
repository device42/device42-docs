## Updating Device42 to Version 19.12.00

Upgrading to 19.12.00 is only possible from 19.05.10 or above. If you need to first upgrade to Version 19.05.10, a link will be provided when requesting an upgrade. We recommend making a backup of your system before any upgrades.

As an interim step toward retiring Advanced Reporting, upgrading to 19.12.00 disables that feature. Administrators can re-enable it if needed, but it will be entirely removed in early 2027. The existing reporting engine has been upgraded to replace the functionality.

The 19.12.00 MA release contains the following features:

Device42 19.12.00 introduces detailed MySQL and MariaDB discovery, improved Oracle software-version discovery, reporting fixes, more readable audit information, and expanded discovery reliability. The release also includes application and operating-system security updates.
