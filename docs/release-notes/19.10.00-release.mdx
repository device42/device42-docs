*Release Date: July 31, 2026.*

## Updating Device42 to Version 19.10.00

Upgrading to 19.10.00 is possible from 19.05.10 or above. If you need to first upgrade to Version 19.05.10, please see those [release notes](https://www.device42.com/blog/2025/04/02/adm-and-ui-enhancements-v19-05-ma/) for details. A link will also be provided when requesting an upgrade. We recommend making a backup of your system before any upgrades.

For up-to-date information, notifications of outages or maintenance, visit our status page at: [https://device42.freshstatus.io/](https://device42.freshstatus.io/).

The 19.10.00 MA release contains the following features:

## Reporting Enhancements

- D42-46279 – Added the ability to easily clone any standard reports
- D42-46275 – Added the ability to use AND and OR within reports. Additionally added date range filters and operators and grid functionality to clear filters and use pagination
- D42-46271 – Added an Export button to the display on screen view, ensured the exports are filter aware and added an edit button to the display on screen view
- D42-33267 – Increased the dropdown limit and added alphabetical sorting to Insights+ dashboard dropdowns
- D42-58637 – Fixed an issue when creating a report where you cannot save a dataset with empty results
- D42-48370 – Fixed an issue where reports and alerts may be sent twice
- D42-47971 – Fixed an issue in Insights+ that could cause certain reports to not display correctly when using custom certificates
- D42-47925 – Fixed an issue that would sometimes prevent saving after editing an alert
- D42-46386 – Manually entered data within EOS and EOL fields will no longer be overridden by our enrichment services. This is now consistent across both software records and operating system records.
