*Release Date: October 8, 2026.*

## Updating Device42 to Version 19.11.00

Upgrading to 19.11.00 is only possible from 19.05.10 or above. If you need to first upgrade to Version 19.05.10, please see those [release notes](https://www.device42.com/blog/2025/04/02/adm-and-ui-enhancements-v19-05-ma/) for details. A link will also be provided when requesting an upgrade. We recommend making a backup of your system before any upgrades.

For up-to-date information, notifications of outages or maintenance, visit our status page at: [https://device42.freshstatus.io/](https://device42.freshstatus.io/).

The 19.11.00 MA release contains the following features:

## Application Dependency Mapping Enhancements

- D42-46085:
  - Improved SQL Server cluster identification and expansion rules for displaying on the application layout
  - Fixed the visualization when adding two application groups into a single Business Service

## Reporting Enhancements

- D42-60951 – Removed the 10,000 row restriction when filtering and exporting DOQL Standard Reports on the Display on Screen page
- D42-46276 – Added a Live Preview toggle and query execution control to the Display on Screen view
- D42-45114 – Added a calculated "Days Undetected" field to the Software Installation DOQL view and list view, enabling more accurate auto-cleaning of software and services
- D42-60798 – Fixed an issue where some DOQL syntax was not being validated in Standard Reports
- D42-61612 – Fixed sync failures that could occur following the introduction of enhanced DOQL validation
- D42-61919 – Fixed an issue where DOQL queries could fail with the error "function not permitted: normalize_resource_details"

## Discovery Scheduling, Automation, and Notifications

- D42-37510 – Added Blackout Scheduling Windows, allowing you to define periods when discovery jobs will not run
- D42-62406 – Blackout Window time settings now align with the settings in **Tools > Time Settings**

- D42-39165 – Added an out-of-the-box automation rule for Operating System Models

Across many aspects of Device42 security has been enhanced. Including updating core OS dependencies and libraries and in product protections.
