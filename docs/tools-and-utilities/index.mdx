This page lists the standalone tools and utilities that you can download and use with Device42. It covers discovery tools, bulk data management tools, migration scripts, and miscellaneous tools such as the ODBC and JDBC drivers.

## Discovery Tools

Use these tools to run discovery jobs from other machines or network segments, or to collect data that the main Device42 appliance can't reach directly.

### D42 Ping Sweep

The Device42 Ping Sweep utility is a self-contained, portable utility that runs a ping sweep on the networks you specify. It uploads the discovered IP addresses (and, where available, MAC addresses and device names) to your Device42 appliance. It runs on Windows or Linux hosts.

To use it, put it in a folder, copy or rename `ping.cfg.sample` to `ping.cfg`, and add your settings. On Linux, run `chmod +x` on the executable. Run the utility as root or as an administrator.

Ping Sweep requires Device42 v11.0.0 or later.

</DownloadCard>

### D42 NetFlow Collector

The Device42 NetFlow Collector is a self-contained, portable utility. Point your network device to it, and it collects and analyzes NetFlow data and sends it to your Device42 instance for enhanced application dependency mapping. It is available for Windows and Linux.

This version requires Device42 v16.00.00 or later. To get an older release, contact Device42 support.

### D42 Packet Capture

The Device42 Packet Capture utility is self-contained and portable. Run it on any network-connected device to collect network packets from the local interface. It can filter and analyze the packets, and then send them to your Device42 instance for enhanced application dependency mapping. It is available for Windows and Linux.

Packet Capture requires Device42 v16.00.00 or later.

## Migration Scripts

### phpIPAM

If you manage IP addresses with phpIPAM, use this script to migrate your IP inventory to Device42. The script connects to the phpIPAM server (v1.2.1 and later), extracts the data, and sends it to Device42 using the REST APIs.

## Miscellaneous Tools

These tools help you print QR codes, upload offline discovery logs, connect to Device42 data with ODBC or JDBC clients, and search Device42 from your browser.

### Device42 QR Code Print Utility

The Device42 QR Code Print Utility gives you fine-grained control over QR code printing. Print QR codes with your Device42 print profiles, or generate codes as needed.

This is a Windows application (Microsoft Software Installer). It is compatible with Device42 9.6.0 and later.
