Standard Reports (under **Analytics** in the main menu) are the recommended option for tabular reporting in Device42. They provide a quick way to query and report on information by integrating with DOQL queries, MA object tables, and the catalog of existing reports. For interactive dashboards and visual analytics, see [Insights+](reports/reports/insights-plus.mdx).

## Create a Standard Report

You can create a standard report in several ways:

- **DOQL query:** Write a custom query against the Device42 database.
- **Pre-defined report:** Use an existing report as a tab in a multi-tab report.
- **List page:** Generate a report from any object list page with filters applied.
- **Guided report:** Select an object type and configure filters through the UI.

### Create a Report Using DOQL

A DOQL statement, or Device42 Object Query Language statement, is a query that can be run against the Device42 database in the **Insights+** interface, through the application, or using the RESTful API. DOQLs can be used in Standard Reporting to generate the data to display in the results table.

:::note
To create reports using DOQL, you should be familiar with and consult the **Data Dictionary** under the **Viewer Schema** option under the help icon.
:::

To use DOQL to create or edit a standard report, name the report and then select **DOQL Query** from the report-type dropdown. Enter the DOQL commands in the text box. The start of a sample select statement is displayed in the DOQL text box. If an error is encountered during parsing (for example, due to invalid syntax or referencing a table or field that does not exist), an error message will show at the bottom of the text box.

Create a multi-tab standard report with one tab containing the results of a previous existing report. Select the **Pre-Defined Report** option and choose from a set of existing reports to be included as a separate tab.

### Create a Report From a List Page

You can create a new standard report from any of the object list pages. A standard report can be emailed and scheduled. For example, you can create a standard report from the following list pages under the **Resources** menu:

- All Devices
- All Assets
- Subnets
- All IP Addresses
- Ports
- Docker Resources
- LXC Resources
- Operating Systems
- Operating Systems in Use
- Software Components
- Software In Use
- Secrets 

From the object list page, apply filters to narrow the data, then click the **Report** button at the top of the table. The filters you applied carry over to the report.

## Clone a Standard Report

Open an existing report and click **Clone** to create a separate copy. The cloned report retains the original report definition, including its DOQL or SQL query, selected columns, and layout. Device42 appends ` - Clone` to the report name to distinguish the copy from the original.

Edit the cloned report to change its filters and configure an independent schedule. Changes to the clone do not affect the original report.

## View, Filter, Export, and Edit Standard Reports

Click **Display on Screen** to view the report results. The results grid provides global search, sortable columns, pagination, and a **Table Columns** selector for showing or hiding columns.

### Filter Report Results

Click the filter icon in a column header to open its filter panel. Add or remove rules, select an operator, enter a value, and choose **Match All** (AND) or **Match Any** (OR) logic. Click **Apply** to filter the results. OR logic can also combine rules for different fields. You can use global search together with column filters.

![Advanced report filters using Match Any with multiple rules](/assets/images/standard-reports/advanced-filter-match-any.png)

Date fields support **Date is**, **Date is before**, **Date is after**, and **Between** operators. Select **Between** and use the two date fields to enter a start and end date.

![Between date filter on Standard Report results](/assets/images/standard-reports/advanced-filter-date-between.png)

Click **Clear Filters** to remove all active filters. Filters remain applied when you sort columns, move between result pages, or export the report.

The following additional actions are available from the **Display on Screen** view:

- **Export:** Select the fields to include and export the report in tab-separated values (TSV) or Excel format. The export applies the active data-grid filters and includes all pages of the filtered results.
- **Edit:** Open the report details page directly in edit mode.
- **Print:** Print the displayed report results.
